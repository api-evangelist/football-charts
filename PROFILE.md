# Football Charts

Transparent football (soccer) statistics and model predictions across 90+ leagues: league tables (classic, luck-adjusted, goals-based), results, fixtures with model probabilities, Dixon-Coles match probabilities, Monte Carlo season projections, goal-timing distributions, team match logs, and a public prediction track record. Offers a free REST API and a hosted MCP server.

- **Provider:** https://www.football-charts.com
- **Documentation:** https://www.football-charts.com/developers
- **Base URL:** https://footballcharts-backend.onrender.com/api/v1

## APIs

- **Football Charts REST API** — Free read-only REST API for football statistics, standings, results, fixtures, match probabilities, season projections, goal timing, and prediction track record. Bearer API key auth with a self-describing JSON descriptor at the root. (`https://footballcharts-backend.onrender.com/api/v1`)
- **Football Charts MCP Server** — Hosted MCP server exposing football statistics tools (list_leagues, get_league_table, get_rankings, get_results, get_fixtures, get_match, get_season_projection, get_team, get_goal_timing, get_track_record) for AI agents. API key embedded in URL path or via Authorization header on POST /mcp. (`https://mcp.football-charts.com/mcp`)

> Both a free REST API (base https://footballcharts-backend.onrender.com/api/v1, Bearer key auth, self-describing JSON manifest at /api/v1/ — not a standard OpenAPI/GraphQL/Postman spec) and a hosted MCP server at mcp.football-charts.com are confirmed. The MCP endpoint can be reached at POST https://mcp.football-charts.com/mcp (Authorization: Bearer) or with the key in the URL path (https://mcp.football-charts.com/fc_your_key/mcp). An open-source local/stdio MCP option also exists via `npx -y footballcharts-mcp` (repo github.com/ddevetak/footballcharts-mcp, npm footballcharts-mcp) — not cataloged as MCPServer since it is a local CLI. No llms.txt or published agent skills found. The submitted apis.json reportedly lists baseURL as https://www.football-charts.com, but the actual runtime API host is the Render backend URL.
